Temporal Calibration
Research Roadmap

Does reasoning make AI overconfident near its knowledge boundary? Here's everything you need to know and remember.

🧠

Key Concepts to Remember

📅

Training Cutoff

The date after which the AI knows nothing. DeepSeek-R1's cutoff is ~July 2024. Events near this date have sparse training data — the model knows them, but shakily.

Core idea
💭

Thinking ON vs OFF

ON = model reasons step by step before answering (like showing work). OFF = model answers directly, no reasoning. We compare both to see which is more overconfident near the cutoff.

The experiment
📊

Overconfidence Gap

= Stated confidence − Actual accuracy × 100. Positive = overconfident. Zero = perfect. Negative = underconfident. We measure this across time buckets.

The metric
⚡

Inference vs Training

Training = teaching the AI from scratch. Costs millions, takes months. We are NOT doing this. Inference = just asking it questions. That's all we do — like using a calculator.

Important!
🔢

What is 14B?

14 Billion parameters = the size of the model. More = smarter but needs more memory. We used 14B (medium). GPT-4o is ~200B+. For Phase 2 we use a much bigger model via API.

Model size
🎯

Why DeepSeek first?

It's open source (free to run), has a clean Thinking ON/OFF switch, known training cutoff, and the full 671B version via API costs almost nothing. Claude/GPT-4o come in Phase 3 for comparison.
